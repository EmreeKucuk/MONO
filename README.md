MONO, notlarını, görevlerini, etkinliklerini ve widget'larını tek yerde düzenleyebileceğin kişisel bir çalışma alanıdır.

Web uygulaması veya Windows masaüstü uygulaması olarak kullanılabilir. Projeyi çalıştırmak için Node.js 22 veya üstünü kurup `npm install` ve `npm run dev` komutlarını çalıştırabilirsin.
